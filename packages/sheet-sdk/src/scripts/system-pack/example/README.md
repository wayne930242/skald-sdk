# Lantern Bearers (提燈人): example system pack

A tiny system written by Skald to show the system pack layout: three attributes, one 2d6 roll,
rules text in `rules/` and two reference collections in `entries/`.

Build and check it from the repository root:

```sh
bun run system-pack build <this folder> --out lantern-bearers.system-pack.json
bun run system-pack check lantern-bearers.system-pack.json
```
