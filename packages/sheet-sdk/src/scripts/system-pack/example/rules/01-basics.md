# 基本規則 {#basics}

每位提燈人有三個屬性：**力量**、**靈巧**與**機智**，數值從 -1 到 +2。開始時把 +2、+1、0 分給三個屬性，再依[出身](#origins)加一。

## 擲骰 {#rolling}

當你做的事有風險，擲 2d6 加上相關屬性：

| 總和 | 結果 |
| --- | --- |
| 10 以上 | 成功，你做到了。 |
| 7–9 | 有代價的成功：主持人給你一個難題或代價。 |
| 6 以下 | 失手，事情變糟，主持人說會發生什麼。 |

### 互相幫忙

說出你怎麼幫忙，然後讓對方的擲骰加一。如果對方失手，你也承受後果。

## 出身 {#origins}

選一個出身：

1. 礦工：力量 +1。
2. 抄寫員：機智 +1。
3. 信差：靈巧 +1。
