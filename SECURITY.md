# Security policy

Report vulnerabilities privately; do not open a public issue.

- Use GitHub's "Report a vulnerability" (private security advisory) on this repository, or email
  wayne930242@gmail.com.
- Include what you found, steps to reproduce, and the affected version or commit.
- The maintainer aims to acknowledge a report within 7 days. This is a volunteer project, so fixes
  have no fixed deadline.

This policy covers code in this repository. The private Skald service is not in scope here; you
can still report problems you notice in it through the same channel.

## 安全政策

請私下回報弱點，不要開公開 issue：使用本儲存庫的 GitHub「Report a vulnerability」，或寄信至
wayne930242@gmail.com。請附上發現內容、重現步驟與受影響版本。維護者會盡量在 7 天內回覆；本專案為
志工維護，修補沒有固定期限。
